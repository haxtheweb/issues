# HAX Roadmap

The ecosystem-level roadmap. Priorities are set in the unified issue queue: larger efforts get a written plan posted as an issue comment and the `Plan Created` label, so this file is a summary of the active directions, not a separate planning process. Repo-specific roadmaps (where they exist) live in each repo and link back here.

## How to influence this roadmap

Open an issue in the unified queue describing the need. Teaching and use-case issues get weighed directly against these lines — HAX is education-first, so classroom needs move the roadmap.
